# PeerScript: AI-Assisted Clinical Workflow & Prescription System

## Overview

PeerScript is an AI-powered web application designed to help physicians streamline clinical workflows, automate medication prescriptions, and manage patient data through an intelligent interface.

The system combines structured patient data management with AI-assisted prescription support, enabling faster, more consistent, and data-driven decision-making.

Built as a team project with a focus on real-world healthcare challenges, PeerScript demonstrates how AI can be integrated into clinical workflows to reduce friction and improve accuracy.

---

## Problem

Healthcare providers face several challenges in day-to-day workflows:

* Manual prescription processes are time-consuming
* Dosage calculations can be error-prone
* Switching between systems slows down decision-making
* Patient data is often fragmented or difficult to manage

These inefficiencies can impact both provider productivity and patient outcomes.

---

## Solution

PeerScript provides a unified interface that:

* Automates prescription workflows
* Assists with dosage calculations
* Suggests alternative medications
* Stores and organizes patient data
* Integrates AI to enhance decision support

This reduces cognitive load for physicians while improving workflow efficiency.

---

## Key Features

* AI-assisted prescription recommendations
* Automated dosage calculations
* Alternative medication suggestions
* Patient record management system
* Searchable and updatable database
* Clean, responsive UI for clinical workflows

---

## System Architecture

1. User input → patient and prescription data
2. Frontend → structured UI (React)
3. Backend → API and data processing
4. Database → MongoDB patient records
5. AI layer → Groq API for recommendation logic
6. UI → results and workflow outputs
